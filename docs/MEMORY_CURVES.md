# 双阶段遗忘与间隔回想

本文说明已实现的普通记忆曲线、回想增强、阈值退出与正文清理。运行配置、账号与记忆保存在使用者自己的数据目录。

## 设计决定

采用快慢两条指数痕迹的加权和，替代单一指数；保留旧曲线读取能力，通过管理配置明确启用。快段权重 0.75、慢段权重 0.25。中等意义且未巩固时，总体首次减半时间等于该层基准半衰期，慢段半衰期为其 4 倍。意义主要延长快段、较少延长慢段；巩固主要延长慢段、较少延长快段。情绪残留和干扰继续参与稳定性，情绪记忆和当前心情使用各自的独立机制。

回想使用实际来源时间。同一轮密集提及只获得一次间隔贡献；再次分散提及增加巩固，并小幅回退痕迹的有效年龄，不改事件日期。意义的回想增量独立记录、最多 0.05；不反复改写事件基础意义。只回想大意不能恢复缺失的细节。合并与真实确认使用同一间隔规则；读取不产生增强。

普通记忆超过阈值后退出检索。再经过保留期，清除正文与正文版本，保留防止旧任务复活的最小墓碑。数据库回收在低频维护中按空闲页比例触发，不在每次聊天执行。外部备份、运行日志和原始聊天有独立保留周期，不能声称删除一条记忆即擦除所有副本。

## 验收依据

检测初始快降和后期相对衰减变慢；S 对快段敏感度更高，C 对慢段更高；纯读取和分步重锚不改变结果。100 次密集提及不能比一次同轮提及更强，分散回想能提高后续保留；意义增量封顶，细节不凭空恢复。切换旧曲线时当前值、正文、来源、事件时间和版本保持。真实删除后正文及历史版本不再存在，墓碑继续阻止旧任务复活。使用临时数据库验证可复用页与必要压缩，不拿界面隐藏当作物理清理。

## 公式与含义

记忆保存快痕迹 f、慢痕迹 l，剩余程度 R=0.75f+0.25l。两条痕迹分别按 f(t)=f(0)·2^(-t/Hf)、l(t)=l(0)·2^(-t/Hl) 衰减；不会在重启时重新分配二者，因而不会反复恢复快段。意义的当前可读程度随 R 减弱，初始事件意义 S0 保持为独立基准。不是事实置信度下降。

设 S=clamp(S0+b,0,1)-0.5，b 为有上限的回想意义增量；C 为巩固，E0 为初始情绪强度，I 为干扰，B 为本层基准半衰期。现有影响参数 kS、kC、kE、kI 继续可配置：

- Hf = clamp(B·q·2^(0.5kS·S+kC·C+0.5kE·E0)/(1+kI·I))
- Hl = max(Hf, clamp(4B·2^(0.1875kS·S+4kC·C+0.5kE·E0)/(1+kI·I)))
- q = ln(2)/ln(0.75/(0.5-0.25·2^(-1/4)))，约 0.729。

clamp 使用已有最小/最大半衰期。默认 kS=8、kC=0.5，所以意义对两段的指数系数分别为4、1.5，巩固分别为0.5、2。旧长期的 kS=12 仍会保留，影响分别为6、2.25。当前选型没有再新增一组重复的可调影响参数。情绪平复与细节连续积分仍沿用原实现，但细节的基础尺度取快段，因此大意能比细节保留更久。意义修正、配置修改不恢复细节。

## 回想

真实来源先做来源去重与审核。间隔尺度 T 默认6小时；相邻回想间隔小于 min(30分钟,T/4) 时属于同一轮。每轮只增加一次信用，信用为 1-2^(-Δt/T)，其中 Δt 是该轮开始与上一轮最后一次提及的间隔；没有固定最低增益。同秒100次确认与一次确认相同，回执仍逐条记录，避免重试和重启重复计入。合并也走同一轮规则，使用所在层间隔设置。

信用累计 n 后 C=1-exp(-n/3)，且不主动降低已有巩固。每次新增信用 u、该层增强比例 g，实际回退比例 a=g·u：f'=f^(1-a)，l'=l^(1-a/4)。这等价于部分回退有效年龄，事件日期不变。回想意义增量 b'=min(0.05,b+0.01a)，不改 S0。这里选择小幅提升意义是为了允许反复真实关注产生重要性，而不让高频词变成重大事件。

延迟来源按真实发生时间计信用，不能因中途配置重锚而丢弃。若距当前计算锚点已过去 τ，则快段恢复量折算为 max(f,f^(1-a)·2^(-τa/Hf))，慢段使用 a/4；不把旧来源刷新为现在发生。巩固从当前锚点向后生效，不重放过去所有配置版本。这是有意采用的轻量近似。迟到材料的到达顺序不保证每个浮点状态完全等同于及时处理，但不会改变事件日期或凭空恢复细节。

## 长尾终点与实体清理

自然曲线不会在有限时刻精确到零。普通未保护记忆按既有曲线衰减至本层遗忘阈值后退出检索并标记删除。没有固定闲置天数造成的截断；较高意义和巩固可自然保留更久。阈值为0时仍保持原来的关闭自动遗忘语义，人工保护和核心不受自动删除影响。

删除后正文默认保留7天，再清空正文和标签，删除正文历史版本、相关图提及/关系、动态信号及数据库内含该记忆的迁移原件与维护/迁移预览。预览过期后需重新准备。保留ID、内容哈希、来源ID、版本与删除墓碑，供延迟任务屏障及派生向量删除使用。实体标签只在不再被其他图记录使用时清除。向量未开启时不会启动编码器；旧派生向量通过现有删除队列在该索引启用时处理，检索侧始终以正式记录是否删除为准。

后台每日维护检查空闲页：至少1MiB且占数据库25%才压缩，聊天不逐条压缩。SQLite压缩会暂时占用额外磁盘及写锁，因此只低频执行。正常滚动备份原有保留最近3份；手工备份和迁移备份不自动删除，原始聊天/媒体/未结束任务也有独立保留逻辑。不能将正文清理解释为所有外部副本或文件系统介质已安全擦除。

## 合成比较

S0=0.5、无巩固/情绪/干扰、基准7天，两种曲线的剩余比例：

| 天数 | 原单指数 | 双阶段 |
|---:|---:|---:|
| 1 | 90.57% | 89.86% |
| 7 | 50.00% | 50.00% |
| 14 | 25.00% | 28.87% |
| 30 | 5.13% | 13.17% |
| 60 | 0.26% | 5.68% |

双阶段在该组中等意义示例中自然降至1%约130天；实际时间由意义、巩固等既有维度决定。本地保留原基准7/180天和已有遗忘阈值，不设统一闲置期限。固定人设与核心仍按原规则。公开版新数据默认仍沿用原曲线，可在管理页按层选择双阶段。

纯数学投影10000次，本机一次测量约51ms；没有新增模型调用、数据库服务或常驻模型。此测量只说明数学运算开销，不代表完整模型检索耗时。新曲线选型由合成数据与工程目标确定，实际养成效果仍需要使用期观察。
