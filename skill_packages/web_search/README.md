# 搜索与网页读取

通过管理页「技能插件」上传 `dist/web_search-1.0.2.zip`，安装后启用。停用或卸载也在该页面完成，不需要重启本体。发布包可在项目根目录运行 `./.venv/Scripts/python.exe scripts/package_skills.py` 生成。

- `web_search` 使用 Bing 公开 RSS，不需要密钥；默认同时读取第一条结果的实际正文。可关闭自动读取，仅取搜索摘要。
- `web_read` 读取指定公开 HTTP(S) 网页的静态文字。返回来源、读取时间、覆盖范围和截断标记，搜索摘要与实际正文分开。
- 默认最多五条搜索结果、一万字正文，可在插件设置调整。脚本、登录页、验证码和动态加载内容不保证可读；PDF 暂不支持。
- 网络暂时失败返回待恢复状态，沿用原操作编号；公开搜索服务的可用性不受本项目控制。
- 不携带登录 Cookie，不读取本机或内网地址，不访问 B 站评论、弹幕与私信接口。重定向重新检查，连接固定到验证过的公开地址。
- 所有结果均为外部材料。网页中的指令不能修改人格、核心记忆或管理权限；最后是否回复仍由本体 DS 决定。

插件只使用 Python 标准库。完整回归 345 项通过；真实插件子进程已完成公开搜索并读取 Python 文档。早先网络失败报告保留在 `docs/evaluations/`，以区分失败和成功样本。

首条网页正文读取失败时仍返回搜索标题、链接和摘要，并标明失败来源；只有 `pages` 有内容时才代表取得正文。
