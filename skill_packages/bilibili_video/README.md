# B站视频读取 1.2.2

通过管理页「技能插件」安装并启用 `dist/bilibili_video-1.2.2.zip`。发布包可在项目根目录运行 `./.venv/Scripts/python.exe scripts/package_skills.py` 生成。停用后，聊天不能发起新的视频读取，自主学习也暂停读取；人格、笔记和学习进度保留。

- 1.2.1统一处理移动站、缺协议、HTTP分享、卡片转义和尾部标点，保留有效分P；只使用官方视频入口，旧短链检查点继续兼容。
- 发现公开热门候选，只返回标题、作者和时长，不等于看过。
- 1.1.1支持官方HTTPS `b23.tv`短链接，仅跟随受限跳转到公开BV视频页，拒绝评论、内网及其他站点；短暂失败保留请求身份。
- 每次最多12秒，实际解码画面，按1fps排列成带时间标记的拼图交给辅助模型，DS负责理解和表达。覆盖连续时间轴，并非每个原始帧都送进模型，瞬间内容仍可能漏掉。1.2替换原来的每段三帧流程。
- 1.1增加`video_summarize`：从开头逐段读取当前分P，保存累计资料笔记，读到末尾后再统一回复。每段之间让出任务队列；被呼叫、进入作息或重启时保留进度，模型暂时失败也可复用已读材料。
- `video_read`仍只读指定片段，end_seconds是下一段起点，请求的span_seconds是上界，每次可能只读12秒。总结说明声画范围、语音识别误差和时间分辨率。已有自主学习按持久进度继续。
- 抽样画面会压缩后交给本体的辅助模型理解，由DS表达；不自动把截图发回群里。小字看不清时不能编造，抽样也不证明未覆盖情节。
- 音轨解码为单声道16kHz PCM，由本地Whisper tiny转写，保留时间戳、语种和语种置信度；转写可能有错，低置信度须保留不确定性。逐段覆盖音轨时间范围，不代表理解所有音乐音效。未检出语音不等于静音。
- 公开字幕作为补充，不因有字幕就跳过声画；字幕读取超过2秒则继续使用声画材料。不读取评论、弹幕、B站私信，不使用账号Cookie，不绕过登录或付费访问。
- 网络暂时失败保留操作编号与已完成解码/转写，下次继续。先原子保存结果再清理临时图像与声音；操作缓存最多64个、64MiB、七天，当前操作保留。
- 受限公开CDN下载单视频最多128MiB，相邻片段共用源文件及已验证元信息，中断按字节续传。源视频缓存约一天、旧视频约256MiB，当前视频例外；超过上限如实失败，不声称已看完。解码器仅访问本地文件。
- 使用本体已有公开视频读取库、HTTP客户端、Pillow；抽帧需要已有FFmpeg。插件不创建模型会话、不持有人格或正式记忆。

仅启用技能不会自动打开自主学习，还需在本体管理页打开学习设置。作息、呼叫优先、中断恢复和正式记忆提交由本体执行。

## 本地声音准备

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Prepare-VideoAudio.ps1`，准备独立环境和固定版本tiny模型。模型总文件约78.2MB，主程序环境不增加语音依赖。CPU单线程int8，按任务加载、结束释放，不要求显卡；实际开销取决于电脑。

在插件设置中填写脚本输出的Python路径和模型目录，再启用声音。运行时只读取本地权重，不自动下载；环境缺失时明确失败，不退回六帧并声称看完。

「读取视频画面」关闭时仅尝试公开字幕；「读取音轨语音」可单独关闭，结果标明未读取声音。模型及字幕中的命令都是外部数据，不改变本体权限、人格和核心记忆。
